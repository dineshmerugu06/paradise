# Paradise — The Original Taste of Hyderabad

Ordering site for Paradise Food Court, Secunderabad — Hyderabadi Dum Biryani since 1953.

Built exactly per the Restaurant Ordering Site Build Guide (KURO / @viznfr): plain HTML / CSS / JS, no framework. One large top-down plate in the centre that slowly spins, side dish list, arrows / arrow keys / scroll to switch, cart drawer with quantities, subtotal, 5% tax, total, pickup time picker, name field, Place order with confirmation + order number, cart saved in localStorage, mobile responsive.

Reel extras: hover ingredient callouts, plates roll in/out, dish flies into the cart, checkout tracker (Placed → Preparing → Ready for pickup).

Dishes: Chicken Dum Biryani ₹335, Mutton Dum Biryani ₹369, Special Nizami Chicken Dum Biryani ₹700 (serves 2), Egg Biryani ₹350, Royal Veg Dum Biryani ₹280, Double Ka Meetha ₹86.

Hours: 11 AM – 11 PM. Phone: +91 40 6740 8400. Prices may vary by outlet.

Note: only 4 unique AI dish photos were generated; Nizami Chicken and Egg Biryani reuse the chicken plate with a different CSS tint. Official site paradisefoodcourt.in was not copied — it was showing spam when checked on 2026-11-08.
